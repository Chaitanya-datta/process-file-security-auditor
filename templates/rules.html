Correlation, Cooldown and Response

Event correlation
Findings for the same process are combined into one alert: those from the same poll, and those from earlier polls within {{ '%g'|format(settings.correlation_window_seconds) }} s.
Alert de-duplication
The same process + same rule + same object is reported once. It can be reported again only after it has been absent for {{ '%g'|format(settings.alert_cooldown_seconds) }} s.
Low / Medium / High
Suggested Action Advisor shows a recommended next step. The process is never changed.
Critical
Protected Process Check first ({{ protected_count }} protected entries). If not protected, the Auto-Response Module performs {{ settings.auto_response_action }}, limited to {{ scope_text }}, and verifies the result with the OS.
Polling
Every {{ '%g'|format(settings.polling_interval_seconds) }} s. Activity shorter than one interval can be missed.
